# Standing V3-B: 자세 보상 scale 단일 변경 실험

V3-B는 25회에서 조기 실패로 판정해 100회로 연장하지 않았다. 보상 대비는 크게 확대됐고 V3-A 25회보다 물리 오차는 줄었지만, 세 seed 모두 zero보다 최대·누적 오차가 컸다. 높은 action 경계 편향과 불완전한 자세 feedback이 남았다. V3-B 변경은 commit/push하지 않았다.

## [V3-A Commit]

commit=`1a6e8497c4b470a911628c1fd6f916c820c428e7`, 메시지=`Add standing V3-A normalization experiment`. branch=`feature/standing-rl`, upstream=`origin/feature/standing-rl`. 일반 push 성공 후 두 HEAD 일치와 working tree clean을 확인했다. 포함 파일은 README·V3-A 보고서·정규화 구현·학습/평가/진단 연결·비교 도구·테스트의 승인된 10개다. `main`과 `origin/main`은 `f2df8dd` 그대로다. 자동 승인 검토의 최초 거절은 이전 금지 지시를 근거로 했고, 최신 첨부의 V3-A commit·push 명시 승인을 읽어 확인한 뒤 재검토에서 승인됐다.

`StandingCfg.orientation_reward_scale`과 학습·평가 CLI에 선택을 추가했다. 기본값은 기존0.05이며 이번 실험만0.01이다. 실제 환경 보상 함수에 이 값을 전달한다. 기존 V1/V2/V3-A 경로는 기본값으로 실행 가능하다. 다른 보상 weight·정규화·물리·관측42D·action12D·action scale·tau0.15초·Stage A 0.5 N×0.5초·10초 episode·64×64 ELU·rollout16·epoch2·minibatch2·gamma0.99·lambda0.95·clip0.2·entropy_coef0.005·std0.3·adaptive LR를 유지했다. PPO config의 차이는 요청한 새 seed뿐이다. 새 학습 seed31415, 준비 seed41415를 명시했다. 가중치 초기값과 준비 자료도 seed에 따라 달라지므로 단일 학습 seed 비교로 보상 scale의 순수 인과 효과를 확정하지 않는다.

## [Gate 판단]

100회 연장하지 않았다. V3-A25보다 최대 오차 약34.72%, 누적 오차 약46.42% 개선돼 일부 개선 징후는 있다. 그러나 zero보다 최대 약1.84배, 누적 약17.56배 악화됐고, 잘못된 국소 pitch feedback과 빠르게 증가한 clipping이 동시에 남았다. 요청된 조기 실패 조건을 우선 적용했다.

수치 판정은 평가 전에 구현했다. 최대>zero×1.5, 누적>zero×2이며 두 축 국소 feedback이 올바르지 않거나 clipping>25%이면 조기 실패다. 이 조건을 충족하지 않고 안전성과 개선 징후가 있을 때만 연장한다. 실제 `gate.json`은 safe=true, promising=true, early_failure=true, extend_to_100=false다. 안정적인 학습 지표나 V3-A 대비 개선만으로 zero 대비 실패를 무시하지 않았다.

V3-B 성공 여부: **실패**. 보상 대비 강화는 실제 궤적과 유한 시간에서 확인됐지만, 세 seed의 zero 대비 자세 오차 개선·복구 성공 기준은 충족하지 못했다. V3-A25보다 나은 결과가 보상 변화만의 재현 가능한 효과라는 결론은 새 학습 seed 단일 실행으로 확정할 수 없다. V3-B를 Standing의 새 기준으로 채택하지 않는다.

## [다음 단계]

이번 근거에서는 action 분포와 clipping 구조를 우선 검토하는 단일 변경 실험을 권장한다. 정상 pre-update KL과 커진 보상 대비에도25회에 요청 clipping47.52%가 발생하고 여섯 관절의 적용 평균이 약−0.96에 머문 직접 증거가 있다. 유계 action 분포를 시험할 경우 변환 후 정확한 log probability와 entropy 처리까지 함께 검증해야 한다. 단순 clamp로 PPO 확률 계산을 바꾸지 않는다. 현재 Gaussian latent action과 환경 clamp의 조합 자체를 likelihood 오류라고 단정하는 것은 아니다.

rollout32는 다음 후보로 남긴다. rollout16의 물리 길이는0.32초이고 더 긴 복구 보상 차이를 직접 담기 어렵지만, GAE와 value bootstrap도 있어0.32초가 전체 학습 horizon이라는 해석은 틀리다. 이번에는 더 긴 rollout의 효과를 직접 시험하지 않았으므로 반복해서 관측한 경계 편향보다 근거가 간접적이다. 보상scale을 더 강하게 만들거나 reset을 축소하지 않는다. Walking과 다음 학습은 수행하지 않았다.

1. scale0.01은 실제 corrective 대비를 약20~22.5배 확대했다. 그러나 PPO 성공에 충분하지 않았다.
2. 25회에 올바른 두 축 feedback은 나타나지 않았다. pitch 상관만 기대 부호이고 국소 pitch 응답은 반대다.
3. 경계 편향은 같은25회 기준으로 감소하지 않았다.
4. 세 seed 모두 zero보다 최대·누적 오차가 컸다.
5. V3-A25보다 scripted와의 물리 격차는 줄었지만 scripted 수준이나 zero 개선에는 이르지 못했다.
6. 새 Standing 기준으로 채택할 수 없다.
7. 다음 단일 후보는 action 분포/clipping 구조를 우선 권장하고 rollout32는 후속 비교 후보로 남긴다.
